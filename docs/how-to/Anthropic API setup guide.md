# Anthropic API setup guide

1. Create or open an Anthropic Console account.
2. Create an API key.
3. In the plugin settings, choose `Anthropic API`.
4. Paste your API key.
5. Keep the default API URL unless you are using a compatible proxy: `https://api.anthropic.com/v1/messages`.
6. Click `Refresh models` to load the models available to your key.
7. Select the model you want to use.
8. Click `Test Connection`.

The plugin sends the text around your cursor to Anthropic when it requests a completion. Review Anthropic's terms and privacy policy before using it with sensitive notes.
