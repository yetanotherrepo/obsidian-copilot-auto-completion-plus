# Gemini API setup guide

1. Create or open a Google AI Studio account.
2. Create a Gemini API key.
3. In the plugin settings, choose `Gemini API`.
4. Paste your API key.
5. Keep the default API URL unless you are using a compatible proxy: `https://generativelanguage.googleapis.com/v1beta`.
6. Click `Refresh models` to load the models available to your key.
7. Select the model you want to use.
8. Click `Test Connection`.

The plugin sends the text around your cursor to Gemini when it requests a completion. Review Google's Gemini API terms and privacy policy before using it with sensitive notes.
